These are the names the model may use when it fills in a field. They come from Home Assistant's names and aliases, which are not always what someone actually says — and sometimes include things that only confuse the model. Editing here changes only what this app offers the model; nothing in Home Assistant is modified.

Names are comma-separated. Uncheck Targetable to keep something out of the enums entirely, so the model can never target it. Reset includes it again with Home Assistant's own names. If you want a name to work everywhere in Home Assistant, add it as an [alias] there instead.
