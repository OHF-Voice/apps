Custom commands

Your own phrasings. Each can fire a Home Assistant intent, run an action (script/scene or a service call), or be STT-only (recognized, then handled by Home Assistant itself). Use {name}, {area}, {floor}, [optional], (a|b), {0..100:slot}.

Devices & Lists

Names pulled from Home Assistant and baked into the grammar. Switch one off to stop recognizing it by voice at all, or add names of your own — comma separated — for anything Home Assistant calls something awkward. Tick only to drop the Home Assistant name and keep just yours, which is the one change that makes the grammar smaller. Aliases are resolved back to the Home Assistant name before the command runs, so they work here but not in Home Assistant's own assistant.

Test recognition

Type what you'd say and see what would fire. Pick a satellite area to stand in for the room the command comes from (used for "in here" style commands), and optionally run it in Home Assistant.

Recognition

Score gate for on-device speech-to-text (this language). A decode is accepted only when its score is at or below this value (lower = more confident). Raise it to recognize more commands, at the risk of acting on misheard speech or noise; lower it to be stricter and let Home Assistant fall back to cloud speech-to-text more often.
